SITUACIÓN AMBIENTAL 01

Residuos sólidos en El Carrasco

¿Cómo cambia la cantidad mensual de residuos enviados a disposición final?

01

Una ciudad que produce residuos todos los días

Los registros de EMAB para 2024 muestran variaciones mensuales en las toneladas de residuos recibidas para disposición final. Usamos estos datos para construir un modelo polinómico educativo.

x Mes del año
R(x) Toneladas de residuos
MODELO POLINÓMICO R(x) = 28,069x² − 46,478x + 26.739,995
✓ Algebraica ✓ Cuadrática

¿Qué nos dice?

El modelo ayuda a visualizar la tendencia de los datos, pero no es una predicción oficial. Un aumento sostenido implica mayor presión sobre los sistemas de recolección, aprovechamiento y disposición final.

02

El clima también tiene patrones

La temperatura no se comporta de manera idéntica durante todo el año. Una función trigonométrica permite representar un comportamiento periódico aproximado.

x Mes del año
T(x) Temperatura media (°C)
MODELO TRIGONOMÉTRICO T(x) ≈ 23,067 + 0,232 sen(2πx/12) − 0,203 cos(2πx/12)
✓ Trascendental ✓ Trigonométrica

¿Qué nos dice?

Las variaciones térmicas pueden relacionarse con consumo de energía, disponibilidad de agua y condiciones de confort urbano. El modelo representa una referencia histórica, no un pronóstico.
